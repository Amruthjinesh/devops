This repository contains my hands-on practice while learning Linux, Bash scripting, Git, GitHub, AWS, and DevOps fundamentals.

## Projects

### Linux System Monitor

A Bash script that checks disk usage, memory usage, and basic system information on a Linux server.

**Features:**
- Disk usage monitoring
- Memory usage monitoring
- Alert threshold at 80%
- Uptime
- Hostname
- Kernel information

### Usage

```bash
chmod +x monitor.sh
./monitor.sh
```
